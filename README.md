# NexScholar Enhancement Project
Software Engineering project focused on enhancing the NexScholar research platform through stakeholder analysis, Agile requirements engineering, and high-fidelity prototyping.

##  📌 Project Overview
* NexScholar is a research-focused platform designed to help students and lecturers discover suitable research opportunities and potential collaborators.

* Following a stakeholder meeting, our team identified several areas where the existing platform could be improved, including research matching, search, onboarding, tutorials, and user engagement.

* The project focused on analysing these needs and designing proposed improvements as a high-fidelity prototype.

## 🎯 Project Objectives
- Improving AI-based research matching and search
- Supporting research discovery and collaboration
- Providing interactive tutorials and guidance
- Personalizing the onboarding experience
- Increasing user engagement

## 🧩 Key Features Proposed

### AI Matching & Search
- Research preferences during registration
- AI-powered and keyword-based search
- AI matching recommendations

### Research Discovery & Collaboration
- Student evaluation and discovery
- Profile preview popups
- External communication links

### Interactive Tutorial System
- First-time user tutorials
- New feature tutorials
- Video and visual tutorials

### Personalized Onboarding
- Personalized onboarding questions
- Tutorial recommendations

### User Engagement
- Achievement badges
- Progress tracking
- Activity notifications
